# Спрайты зданий новой карты GRAM City

`<тип>/stage1.webp`, `stage2.webp`, `stage3.webp` — 21 тип × 3 стадии роста = 63 картинки (WEBP 320×400, прозрачный фон).

| Стадия | Уровни бизнеса | Чем отличается |
|---|---|---|
| 1 | 0–3 | базовое здание |
| 2 | 4–6 | выше, неоновые фонари по углам участка |
| 3 | 7–10 | ещё выше, двойная окантовка, голографический ореол |

- Размер участка: тир 1 — 1×1, тир 2 — 2×2 (Фабрика чипов, NFT-студия, ИИ-лаборатория, Логистический хаб) или 1×2 (Кибер-кафе, Ремзона, VR-клуб), тир 3 — 3×3.
- `manifest.json`: тир, размер участка, синонимы типов (`chip_factory`, `logistics`, `repair_zone`, `cold_storage`…), точка привязки `anchor` (центр участка на земле, в долях картинки) и `footprint_width` (ширина ромба участка в долях ширины картинки) — чтобы движок ставил спрайт точно на участок любого размера.
- Участок 1×2, повёрнутый вертикально (2×1), — та же картинка, отражённая по горизонтали.
- Неон по тиру: 1 — бирюзовый, 2 — фиолетовый, 3 — золотой.
- Это векторные спрайты-заглушки (нарисованы кодом, исходники `docs/skins_src/`), финальный арт заменит файлы с теми же именами.
- Текущая карта эту папку не использует; `sprites/buildings/manifest.json` не тронут.
- Просмотр всех спрайтов: откройте `index.html` из этой папки в браузере.
