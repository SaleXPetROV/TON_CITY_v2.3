# Автоматические переводы (LibreTranslate)

Здесь хранится кеш машинных переводов интерфейса.

- `auto-translations.cache.json` — все переводы, сделанные через LibreTranslate, вместе с исходным текстом.
  Повторный запуск переводит только новые строки или строки, у которых изменился исходный текст.
- `auto-translations.report.json` — отчёт последнего запуска: сколько заполнено, что не удалось.

Приложение читает `src/lib/translationsAuto.json` (его создаёт тот же скрипт).

```
npm run i18n:check                                   # посчитать, чего не хватает
LIBRETRANSLATE_URL=http://127.0.0.1:5000 npm run i18n:autofill
npm run i18n:autofill -- --langs=id                  # только индонезийский
npm run i18n:autofill -- --force                     # перевести заново всё из кеша
```

Ручные переводы в словарях всегда главнее: машинный перевод подставляется только туда, где строки нет.
Чтобы исправить плохой машинный перевод, впишите правильный текст в нужный словарь вручную.
Оба JSON-файла стоит коммитить в git: тогда переводы не нужно генерировать на каждом сервере.
