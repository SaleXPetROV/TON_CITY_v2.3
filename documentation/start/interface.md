# Интерфейс

Нижнее меню, меню ☰ и кнопка «?» на экранах.

Внизу — пять разделов:

- **Карта** — города и участки.
- **Склад** — ваши ресурсы и усилители.
- **Бизнесы** — ваше производство: смены, ремонт, улучшения.
- **Торговля** — рынок, ваши лоты, тендеры.
- **Общение** — лиги, альянсы, чат.

В меню ☰ — Справочник, История, Награды игры, Маркетплейс, Настройки, Помощь, Правила, Дорожная карта.

> На каждом экране, кроме «Бизнесов», в шапке есть кнопка «?» — она открывает статьи именно про этот экран.

---
_Цифры в статье — значения по умолчанию; в игре всегда показываются текущие._
