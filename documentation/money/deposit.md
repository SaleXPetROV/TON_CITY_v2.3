# Пополнение

Как положить GRAM на основной счёт.

1. Нажмите на баланс → «Пополнить».
2. Подключите кошелёк: Tonkeeper, Telegram Wallet или другой.
3. Отправьте GRAM. **GRAM — это монета TON, отправляйте только TON.**
4. Деньги придут на основной счёт: 1 GRAM = 1000 $CITY.

> Отправляйте только с кошелька, подключённого к аккаунту.
