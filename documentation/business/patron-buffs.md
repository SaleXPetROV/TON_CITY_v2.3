# Бафы бизнеса и покровители

Бизнес эшелона 3 может стать покровителем и давать баф подопечным.

Любой бизнес может выбрать покровителя — бизнес эшелона 3.

- Владелец покровителя выбирает для подопечных один из бафов ниже.
- Покровитель получает 1% дохода подопечных.
- Сменить покровителя можно только после перерыва.

| Баф | Что даёт |
|---|---|
| 🔧 Ремонтный допуск | Стоимость починки здания снижена на 25%. |
| 📦 Глубокие закрома | +10% к объёму общего склада. |
| ⚒️ Стахановец | +7% к объёму выпуска при том же потреблении. |
| 🌿 Бережливое производство | Потребление сырья снижено на 5%. |
| 🎲 Второй шанс | 2% шанс, что здание отработает цикл, не потратив сырьё. |
| 🏝️ Оффшорная зона | −1.5% к торговой комиссии при продаже. |
| 📊 Торговый атташе | Увеличивает лимит активных торговых слотов на +1. |
| 🎯 Сенсорный контроль | +3% к шансу на критическое производство (x2 выпуск). |
| 💎 Налоговая льгота | −17% комиссии на вывод средств. |

_Баф выбирает владелец бизнеса-покровителя эшелона 3._

- Баф бизнеса виден в его карточке.
- Бафы ресурсов эшелона 3 — другое: они включаются на складе, см. [Бафы ресурсов эшелона 3](../warehouse/t3-buffs.md).
