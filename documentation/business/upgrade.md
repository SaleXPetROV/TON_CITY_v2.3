# Улучшение

Выше уровень — больше товара и склад; ур. 1 — бизнес ваш навсегда.

- **Ур. 0 → 1** стоит цену бизнеса на карте и только с основного счёта. После этого бизнес ваш навсегда, а выручка идёт на основной счёт.
- Дальше — уровни до 10: больше товара за смену и больше склад, но и больше сырья.
- Улучшение до ур. 2 и выше требует ещё ресурс эшелона 3 — у каждого типа бизнеса свой:

| Бизнес | Ресурс |
|---|---|
| Солнечная станция | Нейро-ядро |
| Свалка | Золотой вексель |
| Шахта Кварца | Лицензия |
| Дата-центр | Фишка удачи |
| Вышка Трафика | Боевой протокол |
| Хладокомбинат | Био-модуль |
| Био-ферма | Код шлюза |
| Завод Микросхем | Нейро-ядро |
| Лаборатория ИИ | Золотой вексель |
| NFT-Студия | Лицензия |
| VR-Клуб | Фишка удачи |
| Логистический Ангар | Боевой протокол |
| Кибер-кафе | Био-модуль |
| Ремзона | Код шлюза |
| Валидатор | Код шлюза |
| Банк Gram | Нейро-ядро |
| Биржа (DEX) | Золотой вексель |
| Казино | Лицензия |
| Арена | Фишка удачи |
| Инкубатор | Боевой протокол |
| Мост (Bridge) | Био-модуль |

_Тот же ресурс нужен на каждом уровне выше 2; сколько штук — на кнопке «Апгрейд»._

- Наградный ресурс эшелона 3 (из плана или City Pass) для улучшения не подходит — нужен свой; наградный можно только включить как баф.
- Цена следующего уровня — на кнопке «Апгрейд».
- Окупаемость при идеальных условиях (смены без перерыва, прочность от 50%, сырьё и товар по цене рынка) — кнопка «Окупится за ~N дн.» на экране бизнеса; в окне улучшения — за сколько дней окупится само улучшение. Это расчёт, а не обещание.

> Арендованный бизнес улучшать нельзя.
