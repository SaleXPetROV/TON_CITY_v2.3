# Скины

Другой вид бизнеса на карте.

Скин меняет вид здания на карте, на работу бизнеса он не влияет.

- Скины дают за задания партнёров.
- Скин выбирается для каждого бизнеса отдельно.
- Арендованному бизнесу скин менять нельзя.
