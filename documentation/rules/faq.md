# Частые вопросы

Короткие ответы на главное.

# Почему пропал товар?

Каждый день в 21:00 МСК часть товара портится — см. [Порча](../warehouse/spoilage.md). Лот без продажи вернулся через 48 часов на склад.

# Почему бизнес не производит?

Нет смены, нет сырья или прочность 0%.

# Почему не могу вывести бонусы?

Бонусный счёт тратится только в игре.

# Почему Город не купил мой лот?

Город покупает только эшелон 1 и только по цене не выше своей.

# Куда делся бесплатный бизнес?

Аренда 3 дня закончилась без улучшения, или его купил другой игрок.

---
_Цифры в статье — значения по умолчанию; в игре всегда показываются текущие._
