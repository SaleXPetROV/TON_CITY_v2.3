## Проверено, проблем нет
- Все админские адреса закрыты проверкой админа; финансовые — более строгой `require_scope("finance")`.
- Пароли хешируются (bcrypt), подпись токенов — только HS256, алгоритм задан явно.
- Вход ограничен по числу попыток; одобрение выплат требует 2FA (в админке и в боте).
- Секретов (`.env`, `jwt_secret.key`) в git нет.
- Сканер bandit: MD5/SHA1 используются только для цвета аватарки и ключа кеша — не для защиты.
- Фронтенд: уязвимые пакеты только в инструментах сборки (react-scripts, jest, eslint, svgo), в браузер игрока не попадают.

## Нужно сделать вам
1. **Сменить**: токен Telegram-бота (BotFather → /revoke), ключ API из тестов, пароль админа. Они остались в истории git; если репозиторий публичный — очистить историю (`git filter-repo`) и только потом выкладывать.
2. В `.env` боевого сервера: `ENV=production`, `MONGO_ROOT_PASSWORD`, `MONGO_APP_PASSWORD`, `PII_ENC_KEY`, `PII_INDEX_KEY` (`python -m scripts.encrypt_pii --new-keys`), копию ключей хранить вне сервера. Затем: `python -m scripts.encrypt_pii --apply`.
3. Включить HTTPS и строку HSTS в `frontend/nginx.conf`; шифрование диска сервера (LUKS / зашифрованный том у хостинга).
4. Позже: перейти со старого `react-scripts` на Vite (уязвимости инструментов сборки), аудит смарт-контракта перед запуском NFT.
