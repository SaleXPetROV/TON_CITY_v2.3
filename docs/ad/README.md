# Рекламный ролик GRAM City (вертикальный 9:16, 33,5 с)

Собран из настоящих экранов мобильной версии игры (390×844, ×3 плотность).

- `shoot.py` — снимает экраны игры в Chromium (нужны запущенные бэкенд и фронтенд, тестовый игрок).
- `shots/` — снятые экраны.
- `composer.html` — монтаж: сцены, тексты, подсветки, живой фон игры. Тексты сцен — в массиве `SCENES`.
- `synth.py` — собственная музыка (синтез, без сторонних треков) → `music.wav`.
- `render.py all` — покадровый рендер 30 fps в `frames/` (нужен `fonts_local.css` с путями к шрифтам из `frontend/public/fonts`).
- Сборка: `ffmpeg -framerate 30 -i frames/%05d.jpg -i music.wav -map 0:v -map 1:a -c:v libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 192k -shortest GRAM_City_ad_9x16.mp4`

## Версия 2 (энергичная, 30 с, 128 BPM)
- `synth2.py` → `music2.wav`: EDM, нарастание → дроп на 3,75 с → второе нарастание (22,5 с) → финал (24,4 с). Собственный синтез, без сэмплов.
- `composer2.html`: сцены режутся по сильным долям (каждый такт), вспышка/наезд/тряска/RGB-расслоение заголовков на смене, пульс свечения на каждой доле, сцена «Меняй скины» (Биоферма: стандартный → Crazy на ударе), быстрая нарезка экранов перед финалом.
- `shoot_skin.py`: съёмка экрана бизнеса с двумя скинами (`shots/biz_std.png`, `shots/biz_crazy.png`).
- Рендер: `python3 render2.py all` → `frames2/`, сборка как выше, но `-i frames2/%05d.jpg -i music2.wav`.
