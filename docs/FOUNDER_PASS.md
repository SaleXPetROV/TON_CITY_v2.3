# Founder Pass и профиль игрока

## Где у игрока
Страница «Бизнесы» → нажатие на блок профиля (аватар, имя, альянс) → окно «Профиль игрока»:
баланс (основной / бонусы), число бизнесов, уровень City Pass, дата регистрации, ссылка на альянс.
Если игроку открыт Founder Pass — внизу плашка «💎 Founder Pass», она открывает тарифы.

Окно тарифов: цена, доля чистой прибыли, сколько мест осталось, лимит выплат (по умолчанию 300 % цены),
право выкупа и обязательное примечание «не публичная оферта, выплаты не гарантированы».
Кнопка «Подать заявку на покупку» создаёт заявку и открывает чат менеджера из настроек.
Покупки внутри игры нет — сделка оформляется вне приложения.
У игрока с долей в окне есть блок «Мои доли»: «получено X из лимита Y».

## Видимость
Пул по умолчанию выключен. Режимы: «только игроки из списка доступа» (id, @username, e-mail или Telegram id)
или «все игроки». Админы видят пул всегда; игрок, у которого уже есть доля, — тоже.

## Админка → вкладка «Founder Pass»
- Доступ и условия: вкл/выкл, режим видимости, список доступа, контакт менеджера, валюта ($ или TON),
  лимит выплат в %, текст для игроков (на русском, переводится автоматически).
- Тарифы: код, название, цена, доля прибыли %, мест всего, «занято вручную» (места, проданные вне приложения),
  метка (Популярный / VIP), вкл/выкл, порядок. Видно «продано / осталось» и максимальную выплату.
- Заявки: «Связались», «Одобрить» (создаёт долю с зафиксированными условиями), «Отклонить».
  О новой заявке приходит уведомление админу в Telegram (TELEGRAM_ADMIN_ID).
- Доли игроков: ручное добавление доли, запись выплат (отрицательное число — исправление),
  статусы «Активна / Лимит достигнут / Выкуплена / Отменена». При достижении лимита статус меняется сам.

## API
- `GET /api/profile/card` — данные окна профиля и флаг `founder_pass`.
- `GET /api/founder-pass?lang=` — тарифы, мои заявки и доли (или `{visible:false}`).
- `POST /api/founder-pass/apply {tier_id}`, `POST /api/founder-pass/applications/{id}/cancel`.
- Админ: `GET/PUT /api/admin/founder-pass/settings`, `GET /applications?status=`, `POST /applications/{id}/status`,
  `GET/POST /holdings`, `POST /holdings/{id}/payout`, `POST /holdings/{id}/status`.

Коллекции: `game_settings {type:"founder_pass"}`, `founder_pass_applications`, `founder_pass_holdings`.
