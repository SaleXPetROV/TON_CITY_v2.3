# Нехватка ресурса у бизнеса («Мои бизнесы»)

- Под картинкой бизнеса — только статус. Надписи «не хватает ресурса» больше нет.
- Если бизнесу не хватает ресурса для работы, плашка «расход в сутки» мигает красным (значок «!»). При включённом в системе «уменьшении движения» не мигает, просто красная.
- Нажатие на плашку открывает окно: какой ресурс, сколько нужно в сутки, сколько осталось на складе и кнопка «Купить» → страница «Торговля», вкладка покупки с фильтром по этому ресурсу (`/trading?tab=buy&resource=<id>`).
- Окно на 9 языках (`MISSING_HINT_LABELS` в `pages/MyBusinessesPage.jsx`).
- Данные: `missing_resources` в ответе бизнесов (`server.py`), у каждого ресурса `available`, `needed_per_hour`, `needed_per_day`.
